# 豆包账号管理器

Windows 上的轻量豆包多账号管理工具，在一个窗口里切换账号，集中查看视频资源和下载记录。

**当前版本：V1（1.0.0），Windows x64 便携版。**

## 下载与运行

到本仓库 **Releases** 下载 `Doubao-Account-Manager-V1.0.0-Windows-x64.zip`，完整解压后运行 `豆包账号管理器.exe`。无需安装 Node.js 或 Python，不要只复制 EXE。

GitHub 自动生成的 “Source code” 压缩包不是软件运行包。本仓库用于免费软件发布、使用说明和问题反馈，不公开软件自有源码。

首次发布包没有账号、登录或下载记录。第一次运行后，在软件内添加管理名称，再分别打开豆包登录。

## 主要功能

- 多账号独立登录、快速切换、分组与名称清单导入导出。
- 当前对话视频资源查看、同视频候选分组与去重。
- 网页下载和资源下载提示、下载记录、实际文件大小显示。
- 默认下载目录、分组下载目录、网页缓存清理。
- 侧栏收起状态保存、托盘运行、一键关闭账号页面。

软件不提供生成额度，不保证所有视频都有更高码率资源。详见 [使用说明](使用说明.md) 和 [免责声明与数据说明](免责声明与数据说明.md)。
